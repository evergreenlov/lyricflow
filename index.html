☁️ Sincronización en la Nube

Sincroniza tus letras en tiempo real entre múltiples dispositivos usando tu propio proyecto de Firebase.

Usa el mismo código en todos tus dispositivos para sincronizar la misma biblioteca de canciones.
Pega el objeto "firebaseConfig" que te proporciona la consola de Firebase.
¿Cómo obtener tu configuración de Firebase gratis?
  1. Entra en Firebase Console y crea un proyecto.
  2. Crea una app web en tu proyecto y copia el objeto firebaseConfig.
  3. Crea una base de datos Cloud Firestore en modo de prueba.
